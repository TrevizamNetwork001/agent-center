# RAG V1 browser test

`rag-v1.cjs` runs Chromium/Playwright in the existing `agent-center-browser:recovery4` image against the isolated `rag-v1-web:8000` Laravel lab. It expects `/lab/demo.json` with conversation/source IDs and `/lab/password` with the disposable lab account password; neither belongs in Git. Evidence output is `/evidence`. The lab uses two fixture tenants (`admin-a@rag.test`, `admin-b@rag.test`) and the existing auth/session/CSRF middleware. Only the external DNS/LLM transport is replaced with a deterministic fixture, explicitly identified in browser-results.json. No production session, key or database is used.

The PHP `Feature/RagTest.php` tests create their own fixtures in PostgreSQL and exercise the real Client/Output contracts with controlled external responses. Use the project `scripts/test.sh` with TEST_PG_CONTAINER, TEST_NETWORK, TEST_OWNER_ENV and TEST_RUNTIME_ENV pointing at a disposable lab. The test database must not already exist; the script creates and drops only agent_center_test. Full regression uses the same script without a filter.

`scripts/rag-lab.sh` prepares the same disposable scenario with generated restricted secrets, independent PostgreSQL and fixture provider. It refuses an existing state directory, container or network; it does not remove/overwrite a prior lab. Requires the project's tooling, PostgreSQL and browser images. Fixture router/seed require RAG_LAB_FIXTURE=1 and are test-only. The script leaves lab data intact; cleanup must target only its explicitly named containers/network and retain state if needed for review.
