1

Prepare a máquina

Escolha uma máquina Linux dentro da rede que deseja observar. Abra um terminal interativo com acesso administrativo.

Sistema compatívelDebian 12 ou 13 com systemd.
Python 3.13Disponível em /usr/bin/python3. Debian 13 já usa essa versão por padrão.
Ferramentascurl, tar e acesso root ou sudo.
Conexão com a CentralAcesso HTTPS de saída na porta 443.

No Debian 12, confirme a disponibilidade do Python 3.13 antes de iniciar. O instalador não substitui o Python do sistema por você.

2

Baixe e instale

Execute as duas linhas abaixo na máquina do provedor. O instalador verifica o kit antes de instalar.

Terminal Linux
curl -fSLo instalar-agent.sh https://agente.trevizamnetwork.com.br/instalar-agent.sh
bash instalar-agent.sh

Baixar instaladorVer como autorizar a máquina →

Execute com bash. O instalador usa sudo quando necessário e, se executado como root, instala sudo caso esteja ausente.

3

Autorize a máquina no painel

O terminal exibirá Aguardando autorização. No cadastro automático, você não precisa copiar nem digitar um código.

  1. Abra Aceitar Agents
    Entre no painel como administrador da plataforma.
  2. Confira a solicitação
    Compare a máquina e a identificação exibidas no terminal. Escolha o cliente correto.
  3. Clique em Aceitar Agent
    Mantenha o terminal aberto até o cadastro terminar. O Agent aparecerá no cliente escolhido.
Abrir Aceitar Agents →

A solicitação automática expira em 30 minutos. Nenhuma credencial está incluída no download; ela é emitida depois do aceite.

Depois da instalação, use o painel

Abra o Agent cadastrado para acompanhar sua presença e gerenciar as operações disponíveis.

IPs e configurações

Confira o IP de origem observado, edite os IPs autorizados e acompanhe a confirmação das configurações.

Diagnósticos

Execute os testes de rede e acompanhe as etapas e evidências até a conclusão.

Atualização

Solicite a nova versão pelo painel. O atualizador verifica o pacote e informa o resultado.

Reinício do serviço

Solicite a manutenção pelo painel. Sem comunicação com o atualizador, a solicitação aguarda conexão.

O IP de origem da instalação é observado pela Central. Confira a identidade da máquina antes de aprová-la. Configuração de equipamentos não é habilitada por esta instalação.

Qual é a diferença entre cadastro automático e código manual?

O instalador desta página envia uma solicitação para aprovação. O cadastro avançado por código, disponível no painel, usa um código de uso único válido por 15 minutos e exibido apenas uma vez.
